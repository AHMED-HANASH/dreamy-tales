# Dreamy Tales - Design Style Guide

## Design Philosophy

**Theme**: Magical Bedtime Stories for Bilingual Children
**Visual Language**: Warm, Dreamy, Educational, and Child-Friendly
**Target Audience**: Children aged 3-12 and their parents

## Color Palette

### Primary Colors
- **Deep Night Blue**: #1a1a2e (main background, text)
- **Soft Lavender**: #9b88b4 (secondary elements, borders)
- **Warm Gold**: #f4d03f (accent color, highlights, buttons)
- **Cream White**: #fef9e7 (text on dark backgrounds, cards)

### Supporting Colors
- **Gentle Pink**: #f8c8dc (story cards, feminine elements)
- **Sage Green**: #a8c090 (nature elements, success states)
- **Soft Orange**: #ffb366 (warm accents, interactive elements)
- **Light Gray**: #f5f5f5 (subtle backgrounds, dividers)

## Typography

### Arabic Font
- **Primary**: 'Amiri' (serif, elegant Arabic text)
- **Secondary**: 'Cairo' (sans-serif, modern Arabic UI)

### English Font
- **Display**: 'Fredoka One' (playful, child-friendly headings)
- **Body**: 'Inter' (clean, readable content text)

## Visual Effects & Styling

### Background Effects
- **Aurora Gradient Flow**: Animated gradient background using deep night blue to soft lavender
- **Floating Particles**: Subtle animated stars and sparkles
- **Parallax Layers**: Gentle movement of background elements on scroll

### Interactive Elements
- **Story Cards**: Lift effect with soft shadows on hover
- **Buttons**: Gentle glow animation and color transitions
- **Language Toggle**: Smooth flip animation between Arabic/English

### Animation Library Usage
- **Anime.js**: Card animations, text reveals, button interactions
- **Typed.js**: Typewriter effect for story titles and descriptions
- **Splitting.js**: Character-by-character text animations
- **p5.js**: Floating particles and magical effects background

### Header Effects
- **Gradient Text**: Story titles with gold-to-lavender gradient
- **Glow Effects**: Soft luminescence around interactive elements
- **Smooth Transitions**: 0.3s ease-in-out for all hover states

## Layout & Composition

### Grid System
- **Desktop**: 12-column grid with 24px gutters
- **Tablet**: 8-column grid with 20px gutters  
- **Mobile**: 4-column grid with 16px gutters

### Spacing Scale
- **xs**: 4px, **sm**: 8px, **md**: 16px, **lg**: 24px, **xl**: 32px, **2xl**: 48px

### Component Styling
- **Border Radius**: 12px for cards, 8px for buttons, 6px for inputs
- **Shadows**: Soft, warm shadows using rgba(155, 136, 180, 0.2)
- **Borders**: 1px solid with subtle colors, no harsh lines

## Cultural Sensitivity

### Arabic Design Elements
- **Right-to-left support**: Full RTL layout for Arabic content
- **Arabic patterns**: Subtle geometric patterns as decorative elements
- **Calligraphic accents**: Beautiful Arabic script as design elements

### Universal Appeal
- **Inclusive imagery**: Diverse characters and cultural representation
- **Gender-neutral colors**: Balanced palette appealing to all children
- **Accessibility**: High contrast ratios, readable fonts, clear navigation
